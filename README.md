# HTML Utilities

A small collection of single-file HTML tools. Each tool is one `.html` file with everything inline. Open it in a browser and it works.

## Tools

| Tool | What it does |
| --- | --- |
| [Markdown Reader](markdown-reader.html) | Paste or drop a Markdown file to read it rendered and wrapped, with adjustable font, size, and line width. |
| [Screenshot Notes](screenshot-annotator.html) | Pin color-coded sticky notes on a screenshot and export the feedback as a ZIP, annotated PNG, or JSON. |

## Running

Open any `.html` file in a browser, or view them on GitHub Pages at `https://kuynkank.github.io/html-utilities/<tool>.html`.
